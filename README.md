# **🗂️ KanbanCraft — Vue Drag‑and‑Drop Kanban Board**

KanbanCraft is an interactive Kanban board built with Vue.  
It focuses on clean component architecture, drag‑and‑drop interactions, and a smooth, modern UI.

This project is part of my full‑stack engineering portfolio and demonstrates:

- Frontend component design with Vue  
- State management and reactive UI patterns  
- Drag‑and‑drop interactions  
- Clean, modular architecture  
- Responsive design and UX thinking  
- CI/CD and production‑ready structure  

---

# **📌 Features (Planned & In Progress)**

### ✔️ Core Features
- Create, edit, and delete boards  
- Add lists/columns  
- Add and manage cards  
- Drag‑and‑drop cards between lists  
- LocalStorage persistence (MVP)  
- Responsive layout
